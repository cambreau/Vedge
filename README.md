# Titre: Restaurant Vedge 

## Contexte: 
Le projet consiste en la création du site web d’un restaurant vegan, avec une navigation simple et intuitive. 
Le site comprend :
- une page d’accueil présentant le restaurant,
- une page dédiée à la franchise de Val-Jalbert,
- une page "Notre philosophie" mettant en avant les valeurs et engagements écoresponsables du restaurant.
